# Render template version

Bumped whenever
[`render_paragraph()`](https://smorabit.github.io/llegir/reference/render_paragraph.md)'s
template changes; recorded in the run-level manifest
([`build_synthesis_manifest()`](https://smorabit.github.io/llegir/reference/build_synthesis_manifest.md)).

## Usage

``` r
RENDER_TEMPLATE_VERSION
```

## Format

An object of class `character` of length 1.
