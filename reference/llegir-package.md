# llegir: deterministic evidence and model-assisted interpretation of gene co-expression modules

Loads a gene co-expression module object (hdWGCNA first), gathers a
standardized bundle of evidence per module via a toolbox of
deterministic R functions, and drafts an evidence-backed interpretation
paragraph via a model-agnostic synthesis layer with faithfulness
checking, confidence fusion, and confidence-gated human review. The
deterministic evidence core has no model dependency; synthesis backends
are pluggable (an offline mock backend, and live structured-output
backends via 'ellmer'). Experimental: the public API is not yet stable.
