# Cell / sample metadata for a module set

Cell / sample metadata for a module set

## Usage

``` r
metadata(ms, ...)
```

## Arguments

- ms:

  A `ModuleSet` object.

- ...:

  Passed to methods.

## Value

A data.frame with one row per cell/sample, matching the columns of
[`expression()`](https://smorabit.github.io/llegir/reference/expression.md)
/
[`module_scores()`](https://smorabit.github.io/llegir/reference/module_scores.md).
