# Per-cell (or per-sample) module scores

Per-cell (or per-sample) module scores

## Usage

``` r
module_scores(ms, ...)
```

## Arguments

- ms:

  A `ModuleSet` object.

- ...:

  Passed to methods.

## Value

A data.frame with one column per module (e.g. hdWGCNA module
eigengenes), one row per cell/sample.
