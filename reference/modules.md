# List the module ids in a module set

List the module ids in a module set

## Usage

``` r
modules(ms, ...)
```

## Arguments

- ms:

  A `ModuleSet` object (e.g. one built by
  [`hdWGCNA_ModuleSet()`](https://smorabit.github.io/llegir/reference/hdWGCNA_ModuleSet.md)).

- ...:

  Passed to methods.

## Value

A character vector of module ids.
