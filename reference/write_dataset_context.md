# Write a dataset context to a JSON file

Write a dataset context to a JSON file

## Usage

``` r
write_dataset_context(context, path)
```

## Arguments

- context:

  A dataset context, as returned by
  [`build_dataset_context()`](https://smorabit.github.io/llegir/reference/build_dataset_context.md).

- path:

  Output file path.

## Value

`path`, invisibly.
