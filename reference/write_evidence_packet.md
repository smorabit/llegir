# Write an evidence packet to a JSON file

Write an evidence packet to a JSON file

## Usage

``` r
write_evidence_packet(packet, path)
```

## Arguments

- packet:

  An evidence packet, as returned by
  [`build_evidence_packet()`](https://smorabit.github.io/llegir/reference/build_evidence_packet.md).

- path:

  Output file path.

## Value

`path`, invisibly.
