# Write the review queue to a TSV file

Write the review queue to a TSV file

## Usage

``` r
write_review_queue(interps, path)
```

## Arguments

- interps:

  A named list of interpretations; see
  [`build_review_queue()`](https://smorabit.github.io/llegir/reference/build_review_queue.md).

- path:

  Output file path.

## Value

Invisibly, `path`.
