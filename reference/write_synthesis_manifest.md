# Write a synthesis manifest to a JSON file

Write a synthesis manifest to a JSON file

## Usage

``` r
write_synthesis_manifest(manifest, path)
```

## Arguments

- manifest:

  A manifest list, as built by
  [`build_synthesis_manifest()`](https://smorabit.github.io/llegir/reference/build_synthesis_manifest.md).

- path:

  Output file path.

## Value

Invisibly, `path`.
